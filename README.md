# pa-detector

日本株のプライスアクション18型を毎営業日検知し、結果をメール配信・Web公開する。

**この検知には優位性が確認できていない。** 過去データ101,918セルで検証した結果、
往復の売買コスト0.20%を上回った型はゼロだった。
そのうえで、観測の記録として運用・公開している。

公開ページ → `docs/index.html`（GitHub Pages）

## 構成

```
pa_detector/     検知・更新・集計のコード
results/         日次の検知結果（CSV、自動コミット）
verification/    バックテスト結果（ページに表示される）
docs/            公開ページ（自動生成）
note/            note貼り付け用の原稿（自動生成）
articles/        Zenn用の記事（自動生成）
```

## 毎日の流れ

```
17:15  GitHub Actions 起動
  → DB差分更新（J-Quants V2）
  → 18型を判定（確定足、初日のみ報告）
  → メール送信
  → results / docs / note / articles をコミット
  → GitHub Pages に反映
```

休場日は DB の最終営業日が当日にならないため、何もせず終了する。

## 設定

| 環境変数 | 既定 | 意味 |
|---|---|---|
| `PA_MIN_TURNOVER` | 50000000 | 売買代金20日中央値の下限 |
| `PA_CONF_B` | 0.5 | 確度Bの閾値（余裕 ÷ ATR） |
| `PA_EXCLUDE` | 14 | 除外する型 |

セットアップは `SETUP.md` を参照。
